# 排查手冊：症狀 → 先查什麼

原則：**不要為了讓畫面平順就把斷線、飽和、異常值濾掉。** debug 需要看見它們。

驗證層級請誠實區分：`接線表核對過` ≠ `編譯成功` ≠ `模擬成功` ≠ `實機成功`。
只有最後一項算數。

---

## Stage 1（Serial）

| 症狀 | 依序檢查 |
|---|---|
| 裝置管理員沒有新的 COM | ① USB 線只有充電線芯 ② 換 USB 孔（避開 hub） ③ 依 USB 橋接晶片裝驅動（CP2102 / CH340） |
| 有裝置但帶黃色驚嘆號 | 缺驅動。看 USB 接頭旁小 IC 的絲印決定裝哪一支 |
| Upload 卡在 `Connecting....` | ① 在它印 Connecting 時按住 `BOOT`/`IO0` 鍵 ② Serial Monitor 沒關掉 ③ `upload_speed` 降成 115200 ④ 換線 |
| `Access is denied` / port busy | 同一個 COM 只能被一個程式占用。關掉 Serial Monitor / Arduino IDE / 其他終端機 |
| Monitor 亂碼 `���` | baud 不符。`monitor_speed` 與程式的 `MONITOR_SPEED` 都要是 115200 |
| Monitor 空白 | ① 按 EN/RST 讓 banner 重印 ② 確認開在正確 COM ③ 確認 Upload 真的成功 |
| 開機印一半就重啟 | 供電問題。Stage 1 沒接任何東西就不該發生 |
| `HB seq` 停住不動 | 程式當掉。看 Monitor 有沒有 backtrace（`monitor_filters` 已開 exception decoder） |

---

## Stage 2–3（FSR）

| 症狀 | 優先排查 |
|---|---|
| 讀值一直很低（接近 0） | ① FSR 有沒有真的供到 3.3V ② FSR 兩腳在麵包板上接觸是否可靠 ③ ADC 是不是接在分壓**中點**而不是接到 GND 側 ④ 固定電阻阻值太小 |
| 讀值一直很高（接近 4095） | ① ADC 腳是不是誤接到 3.3V 軌 ② 固定電阻是不是沒落在同一節點 ③ attenuation 設定造成飽和 |
| 數值很飄 | 浮接、沒共地、杜邦線接觸不良、麵包板鬆、供電不穩。**先排除硬體再考慮濾波** |
| 兩片 FSR 完全同步 | ① SENSE 節點誤共用 ② 程式讀到同一支 pin ③ 兩個分壓共用了同一顆固定電阻 |
| 按很用力但讀值不再變 | 已飽和。這**不代表接線壞掉**，換較小的固定電阻可以把靈敏區間往上移 |

記得先記錄三個基準：**未按壓基線 / 正常按壓 / 用力壓到飽和**。

---

## Stage 4（IMU）

| 症狀 | 優先排查 |
|---|---|
| I2C scanner 掃不到任何位址 | ① SDA/SCL 是否對調 ② 有沒有共地 ③ 模組有沒有供電 ④ 上拉電阻 ⑤ 該模組其實是 SPI 介面 |
| 掃到位址但軸值明顯錯誤 | 實際晶片與所用 library 不符。**掃到位址只代表有東西回應，不足以認定型號**。要靠 WHO_AM_I 暫存器或晶片絲印 |
| 靜止時加速度不是 0 | 正常。靜止的 accelerometer 仍然量到重力，某一軸約 ±1 g |
| 陀螺儀靜止時不是 0 | 正常。gyro 有零偏（bias）。**不要求所有通道歸零才算成功** |
| 單位對不上 | 看 library 定義：`g` 還是 `m/s²`、`deg/s` 還是 `rad/s`。不可混用，輸出時要標明 |

IMU 給的是加速度與角速度。它**還不等於**可靠位置、完整姿態，更不等於「已辨識抱抱」。

---

## Stage 5（LCD）

| 症狀 | 優先排查 |
|---|---|
| 背光亮但畫面全白／全黑 | controller 型號錯、初始化參數錯、CS/DC/RST 接錯、SPI 沒訊號。**背光亮不代表 controller 有被初始化** |
| 完全不亮 | 背光腳沒供電、VCC 沒接、邏輯電壓不符 |
| 接上 LCD 後板子一直重啟 | 短路、供電能力不足、接錯腳、上電湧流。看 Monitor 有沒有 `BROWNOUT`（Stage 1 的 banner 會印 reset reason） |
| 顏色顛倒 / 鏡像 / 有位移 | 初始化參數（offset、rotation、色彩順序 RGB vs BGR）與實際面板不符 |
| 畫面更新時 Serial 數據卡頓 | LCD 更新與感測取樣要分開排程，顯示不能阻塞採樣 |

---

## Stage 6（整合 / 可視化）

| 症狀 | 優先排查 |
|---|---|
| 圖表某一組看起來是直線 | 不同單位／尺度共用同一個 Y 軸。FSR 的 0–4095 和 gyro 的 ±250 放一起就會這樣。分開畫 |
| 資料看起來停住 | ① 真的沒更新 ② 欄位解析錯 ③ COM 被別的程式占住 |
| Plotter 畫不出來 | 中文 debug 訊息混進資料串流了。切換模式時要明確定義 header 與非資料行 |
| 錄 CSV 時抓不到 port | Serial Monitor / Plotter 還開著。**一個 COM 同時只能一個讀取程式** |

資料來源必須明確標示 **live real / replay recorded / mock** 三選一。
沒收到真實訊號時不可以自動補資料假裝還在連線；通訊中斷要顯示 `disconnected` 或 `stale`，
不能把最後一次讀值當成仍在更新。
